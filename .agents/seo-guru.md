## 17. Canonicalisation and Indexing

* Parameter URLs
* Duplicate homepages

* Tag or category archives

* Thank-you pages

Use `noindex` only where justified.

Ensure the production domain is configured correctly in Jekyll:

```yaml

```

Do not allow production canonical tags to reference localhost, GitHub preview domains, Vercel previews or old domains.

* Allow legitimate search-engine crawling

* Exclude only areas that should not be crawled

Do not block major AI or search crawlers without an explicit business decision.

Document any crawler restrictions that already exist.

## 31. 404 and Error Handling

Ensure invalid or removed URLs return a useful 404 experience.

For SPA/static deployments:

* Add a catch-all route that renders a clear not-found page.
* Include links back to key pages such as Home, Services, Projects and Contact.
* Avoid showing normal page content for invalid URLs.
* Where hosting supports it, return a real HTTP 404 status for unknown URLs.
* Do not index 404/error pages.
* Track common broken URLs so internal links and external references can be corrected.
